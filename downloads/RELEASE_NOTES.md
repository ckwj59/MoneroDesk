# MoneroDesk v1.0.1

## Author allocation restored
- The main payout address remains empty. Enter your own address before mining.
- The author recipient is prefilled and fully visible: `48Rd53h2a9aT1wYnMF6VtVZab189WPVR5jgVf6UedT4iRiLNX91MoA5GydXdu5oMVeSZZCv1H86wKR91V6bBZXCu4LpLusv`.
- Optional 1% mining-time allocation is enabled by default. Users can turn it off on the Mining page.
- The author receives accumulated runtime 20:00–21:00, then 120:00–121:00, 220:00–221:00, and so on. The remaining runtime uses the main address. This is mining-time allocation, not an exact coin transfer.
- Existing explicit user choices remain saved. No personal main wallet, mining logs, account cache, or energy history is distributed.

## Included features
20 languages and matching reference currencies, local/authorized remote node and pool CPU mining, percentage thread controls, separate pool earnings, payout threshold read-back verification, controlled pool switching, and saved-language desktop naming.

Download and fully extract `MoneroDesk-Windows-x64-v1.0.1.zip`. Run `MoneroDesk.exe` and preserve the directory structure. The package includes corresponding modified engine source and third-party license notices. Check `SHA256SUMS.txt` before use.

Estimated earnings are not guaranteed income. Whole-system power readings depend on hardware support. Pool and network fees are provider-controlled. Reaching a payout threshold does not guarantee immediate payment.
